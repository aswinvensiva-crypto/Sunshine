# Evaluation Reports — Sunshine IQ

All reports in this directory are machine-generated by `evaluation/reporter.py`.
Do NOT edit them manually.

## Data Source Labels
- `synthetic`: Results are plumbing/feasibility evidence only (DAT-002, EV-006).
  Business performance claims cannot be made from synthetic results.
- `real`: Results reflect actual system performance on real data.
- `mixed`: Combination; report details which portions.

## PRD Business Targets
The following targets from PRD §7 are HYPOTHESES TO TEST, not acceptance thresholds:
- 10%+ revenue lift from dynamic pricing
- 15%+ reduction in cancellation losses  
- 50%+ reduction in repetitive guest inquiries
(U-11, EV-007)

## Report Fields
Every report contains: module, run_id, tenant_id, data_source, seed, model_version,
git_commit, python_version, generated_at, metrics, notes.
